Project 1 — Global education systems¶

Session 2: load and understand the data¶

AI Clinic · PGE1-EN

Context¶

We work for the start-up EducationTech, which wants to expand internationally. Our manager asks whether the World Bank's education data (EdStats) can help choose the countries or regions to expand into.

Question to solve¶

Can this data help decide in which countries or regions the company can expand?

Steps of this notebook¶

  1. Load the five files with pandas
  2. Explore each dataframe, one at a time: dimensions, columns, preview, duplicates, missing values, values of the main columns
  3. Link the dataframes: which columns do they share, and do the values match?
  4. Summary: diagram of the links, 5 points to watch, question for the next session

No cleaning and no selection of indicators here: this session is only about understanding what we have.

def overview(df, name):
    """Dimensions, duplicates and a per-column summary (type, missing values, distinct values, example)."""
    print(f"{name}: {df.shape[0]:,} rows x {df.shape[1]} columns | fully duplicated rows: {int(df.duplicated().sum())}")
    return pd.DataFrame({
        "dtype": df.dtypes.astype(str),
        "missing": df.isna().sum(),
        "% missing": (df.isna().mean() * 100).round(1),
        "distinct values": df.nunique(),
        "example": df.apply(lambda s: s.dropna().iloc[0] if s.notna().any() else None).astype(str).str.slice(0, 50),
    })

What we learn about data

  • Shape. A complete grid: 242 "countries" × 3,665 indicators = 886,930 rows, no duplicate. Years are in columns (wide format), from 1970 to 2100.
  • Missing values. 91 % of the cells are empty and 60 % of the rows have no value at all. Coverage peaks around 2010 and collapses after 2015 (2016 almost empty, 2017 empty).

def compare(left, right, left_name, right_name):
    """How many distinct key values of `left` are found in `right`, and the reverse."""
    L, R = set(left.dropna()), set(right.dropna())
    return {"link": f"{left_name}  ->  {right_name}", "distinct left": len(L), "found in right": len(L & R),
            "missing in right": len(L - R), "only in right": len(R - L), "examples missing": sorted(L - R)[:3]}

Reading the diagram. data is the central table: it holds the values. country and series are its two dictionaries (who is this country? what is this indicator?). country_series and footnote are notes, attached to a pair or to a single value. 4. Summary¶

Five points to watch¶

  1. The data is mostly empty, and old. 91 % of the cells of data are missing and 60 % of its rows hold nothing. Coverage is best around 2010–2015; 2016 is almost empty and 2017 is empty. Any recommendation will rest on figures that are several years old.

  2. Not every row is a country. 25 of the 242 "countries" are aggregates (World, regions, income groups): counting them would double-count everything. They cannot be identified simply by "no region": Gibraltar and Nauru have no region either, and British Virgin Islands is missing from country altogether.

  3. The keys do not match as they are. Column names differ between files (Indicator Code / Series Code / SeriesCode), 53 indicator codes differ by a trailing space or by letter case, and footnote.Year is text (YR2001). Without normalisation, joins silently lose rows.

  4. Observations, estimates and projections are mixed. 308 indicators are projections running to 2100, and about 7 % of the observed values are flagged as estimates in footnote. A forecast or an estimate must not be read as a measured fact.

  5. The metadata is not fully consistent. 462 indicators are named differently in data and series (e.g. GDP in constant 2005 vs 2010 US$), World Bank regions are not continents, and every file ends with an empty column. Definitions must be checked in series before an indicator is used.
